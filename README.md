# Raider BioLab

Interactive biology simulations for Regis Jesuit Bio, Honors Biology and AP Biology, in the style of PhET.

**Live site:** https://rjedtech.github.io/Raider-BioLab/

## Simulations
- **Cellular respiration**: the inner mitochondrial membrane, electron transport and ATP synthase. Variables: oxygen, fuel, NADH/FADH₂, cyanide, oligomycin, DNP.
- **Enzyme activity**: temperature, pH, substrate concentration, competitive and noncompetitive inhibitors. Amylase, pepsin and Taq.
- **Photosynthesis**: the Elodea bubble lab. Variables: lamp distance, CO₂, temperature, light color.

Each simulation has a **Bio / Honors / AP** level switch, live graphs, a trial data table that copies as CSV, and predict-then-test challenges.

Link straight to one simulation with `#respiration`, `#enzymes` or `#photosynthesis`.

## Privacy
Single HTML file. Everything runs in the browser, with no logins or data collection.

Models are simplified for instruction, and rates are in model units.
