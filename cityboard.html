About the flags

  • Automatic mode: you assigned By hand, but this code was made in Automatic mode (the student opened the tool without your link).
  • Saw automatic scores first: the student calculated by hand, but this browser had already shown the automatic scores for the same scoreboard.
  • Different scoreboard: the code was made with weights that differ from yours.
  • Not from your link: the code does not carry your assignment code.
  • Code edited: the code was changed after the tool made it.
  • Different depth: you locked a depth (Basic, Standard or Advanced), but the code was made at another one.

Flags are clues to talk about, not proof. A student could use another device, or a classmate’s screen, and no flag would show.
